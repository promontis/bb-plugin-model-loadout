Choose your everyday models from one fast, focused selector in BB's composer.

## A model loadout that stays out of the way

Model Loadout gives you a compact, searchable popup inspired by Conductor. It
shows only the models you selected, along with their provider, reasoning effort,
active state, and BB's fast service tier. Changing a selection uses BB's native
composer APIs, so provider handoffs and model changes keep their normal BB
behavior.

## Configure it visually

The settings page provides five loadout slots plus live model catalogs for all
enabled providers. Add or remove models with a click, drag them into the order
you prefer, and save a default reasoning effort for each entry.

The configuration is stored locally in the plugin's BB storage. No external
account, network service, or API key is required.
